# Trishal Varma Mudunuri — Portfolio

Personal portfolio live at **https://mtrishal123.github.io**.

Built with React 19, TypeScript and Vite. Deployed to GitHub Pages by GitHub Actions on every push to `main`.

## Develop

```bash
npm install
npm run dev      # local dev server
npm run build    # production build into dist/
```

## Editing content

All text — profile, experience, projects, skills, education — lives in [`src/data.ts`](src/data.ts).
Replace `public/resume.pdf` to update the resume.
